# 固定来源真实环境案例

少量开源 SDK／组件案例，用于暴露合成样例覆盖不到的 **DOM／Realm／异步／指纹／WASM** 等真实依赖形状。案例资产在 `cases/`；额外上游树默认不捆进发行包。

## 固定上游方法

1. 只选与补环境直接相关的上游；保持其目标 JS 逻辑。不导入整套 VM、加解密专题或采集样例库。
2. 每个来源写明：repository、commit 或精确版本、下载 URL、archive 名、**SHA256**、许可证、准备命令。
3. 准备脚本下载后必须校验哈希；缓存命中仍校验。哈希或版本变更视为换题，须改 pin 与说明，禁止静默替换。
4. 准备输出写到仓库外的新目录（或明确 gitignore 的 vendor）；保留 `PREPARE.json`／`SHA256SUMS`／许可证文本。

## 每例须声明

| 项 | 要求 |
| --- | --- |
| 原始输入 | 调用入口与关键选项 |
| 环境后端 | 如 jsdom／vm／addon；哪些能力真实、哪些占位；**DOM 案例须在声明的页面 Realm 内加载 SDK**（禁止默认宿主 `require(dist)`＋挂全局冒充） |
| 完成信号 | Promise／回调／产物字段何时算完成 |
| 消费观察 | 用哪些检查发现环境或资源错误（正例与反例） |
| 真实 vs 模拟 | 上游逻辑 vs 本地宿主／本地消费方 |
| 边界文案 | **本地模拟通过 ≠ 真实网站接受**；不得写绕过率 |

## 反例（有意义，而非仅“无异常”）

至少覆盖一类：原型归属错、资源错版、异步回调未完成；有 DOM／Realm 声明时另须覆盖 **Realm 错**与**组件错误不得静默成功**。反例须能被该例**已声明**的消费观察发现。
