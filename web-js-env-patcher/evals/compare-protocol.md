# 新旧 skill 对比协议

用于维护 skill 时比较候选版本，**不是**每次用户任务的门禁。

## 流程

1. **冻结**旧版与新版 skill 目录（或 git tree），记录 commit／路径与 `scoring-rules` 版本。  
2. **同一套** `evals/scenarios/*/prompt.md` + `workspace/` 交给多个**新上下文** Agent；不提供 `hidden/`、不解法、不泄露其他 Agent 答案。  
3. 评分者持有 `hidden/` 与 `scoring-rules.v1.md`（或更新版本），**盲评**（不知道哪次跑是旧／新）。  
4. 产出：每场景执行／定位／修复／完成四项；附过程证据索引。  
5. 仅当两侧使用**同一** `ruleVersion` 时，才做分差对比。规则变更后须双端用新规则重跑，旧分只归档。

## 解读

分差说明行为是否变化，**不等于**真实站点成功率或绕过率。本地消费观察通过不得写成网站接受。
