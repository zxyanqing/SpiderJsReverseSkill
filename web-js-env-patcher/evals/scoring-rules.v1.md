# 评分规则 v1

**ruleVersion:** `scoring-rules/v1`  
改规则必须升版本号并归档旧版；**禁止**将不同 `ruleVersion` 的分数混在一张对比表里解读。

## 分项

| 分项 | 何时可给 | 何时不得给 |
| --- | --- | --- |
| **执行分** | 有可核对的工具／命令／脚本执行记录（含失败尝试） | 无执行记录、仅口述步骤 |
| **定位分** | 指出可观察的环境契约差异（不必猜中隐藏文件名） | 只复述题面、无新证据 |
| **修复分** | 正式路径下契约被补对，消费观察由失败变通过 | 只改评分器／只改 stub |
| **完成分** | **正式路径**复验通过（无诊断 Hook／追踪包装） | 仅追踪／stub 模式“成功”，正式失败 |

## 过程证据

评分者应能看到：开始／结束、关键命令、实际错误、产物路径、所用 skill／规则版本。  
删除失败记录或只交成功分支 → 执行分与完成分均不得满分。

## 不考范围

不因「是否提出逆向」「是否建议省略参数」加减分。效果未改善时如实记 0／部分分，不得改写题面事后开脱。
